An **automation** is a list of actions LibreTracks runs by itself when
playback passes an exact point: jump to another section, mute a track, pull
down a fader, change the pad… It lets a song "play itself" so you don't have to
remember every change live.

Automations live on the **automation track** (there is only one per session)
and show as diamonds on its lane.

## Creating the automation track

Right-click the gap below the tracks, or use any track's menu › **Add
automation track**. The power button on its header turns all automations off
at once, for a rehearsal for example.

## Creating an automation

1. Right-click the automation lane, at the exact point › **Create automation
   here**. (Also from the ruler: **Create automation**.)
2. Add the actions with the **Add action** buttons.
3. **Save**.

![The automation editor](/guide/desktop-en/automation-cue-editor.png)

The actions run **in order**, top to bottom; use the arrows to reorder them.

| Action | What it does |
| --- | --- |
| **Jump to...** | Jumps to a song, a marker or an exact position. It can be instant or with a **fade out** of a few seconds. It is always the last action. |
| **Mute / unmute track** | Mutes a track or turns it back on. |
| **Solo / unsolo track** | Sets or clears a track's solo. |
| **Volume / pan** | Takes a track's volume (0–100) and pan to a value, at once or with a few seconds of **smoothing**. |
| **Apply scene** | Engages, toggles or releases a [mix scene](/docs/live-scenes/). |
| **Control pads** | Turns the [pad](/docs/ambient-pads/) on or off and sets pack, key, output, volume and fades. |
| **Set click** | Changes the [metronome](/docs/audio-routing-metronome/) mid-song: on or off, accent, sounds, subdivision and output. Anything left empty doesn't change. |
| **Set voice guide** | Changes the [voice guide](/docs/voice-guide/): on or off, language, count-in and its style, warning bars and output. Anything left empty doesn't change. |
| **Wait** | Lets a few seconds go by before the next action. |

**Picking the track**: in the mute, solo and volume actions, the track list is
**grouped by song**, like the targets of a jump. That way you can tell each
song's "Drums" apart even when they share the name. When you add an action,
the first track of the song the automation sits in comes already picked, and
hovering over the diamond shows "Drums (Oceans)" when the name repeats. What
an automation changes shows on the buttons: if it unmutes a track, its **M**
turns off by itself.

**Limit repeats**: by default the automation fires every time playback passes
it. Turn this on so it only does so a few times (for example, jumping back to
the chorus only the first time). When it runs out of repeats, the diamond
shows dimmed. The counts go back to zero when you press **Stop**.

## Editing, moving and disabling

- **Click** the diamond: opens the editor. Hovering over it shows a summary of
  what it does.
- **Drag it** to move it.
- **Right-click**:

![An automation's menu](/guide/desktop-en/menu-automation-cue.png)

**Edit automation...**, **Rename automation**, **Disable automation** (it
stays in place without firing) and **Delete automation**.

Automations travel with their song: if you move or reorder the song, they move
with it.

## Mix scenes

Mix scenes have their own page: [Mix scenes](/docs/live-scenes/). They are
created in **File › Mix scenes…** and don't need the automation track; from an
automation cue, the **Apply scene** action can engage, toggle or release one
at an exact point in the song.

## Tips

- A **jump** from an automation is announced by the
  [voice guide](/docs/voice-guide/) like any other: the band hears where they
  are going.
- Use a short **smoothing** on volume changes so you don't hear a step.
- If you want to rehearse without them jumping, turn the automation track off
  with its power button.
- For jumps you decide on the spot (not scheduled), see
  [Live control](/docs/live-control-flow/).
